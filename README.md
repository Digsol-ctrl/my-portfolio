# My Portfolio

A sample personal portfolio website built with plain HTML, CSS, and JavaScript — created to practice the git workflow.

## Features

- **Hero section** with animated gradient headline and CTA buttons
- **About section** with a profile avatar and bio
- **Projects section** with three sample project cards (gradient thumbnails, tags, links)
- **Skills section** with animated progress bars (Frontend, Backend, Tools)
- **Contact form** with client-side validation and simulated submission
- **Responsive design** — works on mobile, tablet, and desktop
- **Sticky navbar** that becomes opaque on scroll
- **Scroll-reveal animations** via IntersectionObserver

## Structure

```
my-portfolio/
├── index.html   # Main HTML structure
├── styles.css   # All styles (dark theme, responsive)
└── script.js    # Interactivity (nav, skill bars, contact form)
```

## Running locally

Open `index.html` directly in your browser — no build step required.
